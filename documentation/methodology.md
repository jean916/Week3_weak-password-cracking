
# Project Methodology

## Method 1: Online Hash Crack and John the Ripper

1. Select an authorized locked PDF document.
2. Upload the PDF to Online Hash Crack.
3. Extract the PDF password hash.
4. Transfer the extracted hash to John the Ripper.
5. Perform password recovery.
6. Examine the results.

## Method 2: NetworkWalks

1. Open NetworkWalks Hash Calculator.
2. Calculate or obtain the required hash.
3. Copy the generated hash.
4. Open NetworkWalks Password Cracker.
5. Submit the hash.
6. Examine the password-cracking results.
