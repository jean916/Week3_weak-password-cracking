
# Project Overview

## Title
Weak Password Cracking Lab

## Introduction

This project focuses on understanding password security and recovering passwords from protected PDF documents.

The practical exercise involved extracting password hashes from PDF files and testing password recovery using John the Ripper and online password-cracking tools.

## Tools Used

- Online Hash Crack
- John the Ripper
- NetworkWalks Hash Calculator
- NetworkWalks Password Cracker

## Main Goal

To understand how weak passwords can be vulnerable to password-cracking techniques and why strong passwords are important.
