
# Project Findings

## Observations

The practical exercise provided experience with:

- Extracting password hashes from protected PDF documents.
- Using John the Ripper for password recovery.
- Working with online hash calculation tools.
- Exploring online password-cracking techniques.
- Understanding the risks associated with weak passwords.

## Lessons Learned

The exercise demonstrated why strong passwords are important and how password-cracking tools can be used in authorized security testing.

## Conclusion

Password security is an important part of information security. Using strong and unpredictable passwords helps protect confidential documents against unauthorized access.
